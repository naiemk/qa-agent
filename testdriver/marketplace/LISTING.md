# Week 2+ — optional GitHub Marketplace listing

**Not required for customers to install.** Public App install URL works without
Marketplace review. Use this file when product wants Marketplace discovery.

- [ ] App is public and installable via `/apps/<slug>/installations/new`

- [ ] Support / docs URL (can be `testdriver/README.md` on the public repo)

- Review often ~2–6 weeks (no public SLA)
- Keep shipping customers on the direct install link while the listing is pending
- Listing draft lives in GitHub Marketplace UI; keep notes here for the team

- Block day 7–10 public launch on Marketplace approval
- Put Marketplace billing webhooks into Magpi Test core
